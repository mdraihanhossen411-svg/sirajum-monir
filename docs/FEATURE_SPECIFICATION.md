# Feature Specification

## Overview

This document describes all features of the Sirajum Monir application.

The goal is to provide an offline-first Islamic companion with a clean and modern user experience.

---

# Home

Purpose

Provide quick access to all major modules.

Features

- Daily Verse
- Daily Hadith
- Prayer Time Summary
- Continue Reading
- Recent Activity
- Quick Access

Future

- Personalized Dashboard

---

# Quran

Purpose

Features

- Surah List
- Juz List
- Verse Details
- Bookmarks
- Search
- Tafsir
- Translation
- Audio
- Notes

Future

- Memorization Mode
