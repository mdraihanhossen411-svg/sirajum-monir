# Contributing to Sirajum Monir

Thank you for contributing to Sirajum Monir.

## Development Rules

- Follow Clean Architecture.
- Write clean and readable code.
- Keep files small and organized.
- Use meaningful commit messages.
- Test before committing.

## Branch Strategy

- main → Stable
- develop → Development
- feature/* → New Features
- fix/* → Bug Fixes

## Commit Message Examples

feat: add Quran screen

fix: prayer time calculation

docs: update architecture

refactor: improve home module

## Code Style

- Use Dart formatting.
- Follow Flutter lints.
- Keep widgets reusable.

## Pull Requests

- Explain what changed.
- Link related issue if available.
- Ensure the app builds successfully.

Thank you for helping improve this project.
