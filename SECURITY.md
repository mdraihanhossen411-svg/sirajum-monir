# Security Guidelines

## Overview

This document describes the security principles of the Sirajum Monir application.

---

## Data Protection

- Store data locally by default.
- Encrypt sensitive information when needed.
- Never expose private user data.

---

## Permissions

The application only requests permissions that are necessary.

Examples:

- Notifications
- Storage (if required)
- Internet (future sync)

---

## Authentication (Future)

- Firebase Authentication
- Google Sign-In
- Email Authentication

---

## API Security (Future)

- HTTPS only
- Secure API keys
- Token-based authentication

---

## Privacy

- No unnecessary data collection.
- User data remains under user control.

---

## Best Practices

- Keep dependencies updated.
- Validate user input.
- Protect against common vulnerabilities.

---

May Allah protect this project and its users.

Ameen.
