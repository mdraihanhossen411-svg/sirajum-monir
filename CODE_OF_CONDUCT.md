# Code of Conduct

## Our Pledge

We are committed to making participation in the Sirajum Monir project a respectful, welcoming, and positive experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Be respectful and kind.
- Be patient and helpful.
- Accept constructive feedback.
- Focus on improving the project.
- Respect different opinions.

Examples of unacceptable behavior include:

- Harassment or personal attacks.
- Hate speech or discrimination.
- Offensive language.
- Sharing private information without permission.
- Any behavior that harms the community.

## Responsibilities

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces, including GitHub Issues, Discussions, Pull Requests, and other community interactions.

## Enforcement

Instances of abusive or unacceptable behavior may result in warnings, removal of comments, or restriction from contributing.

## Contact

If you have any concerns, please contact the project maintainer through the GitHub repository.
